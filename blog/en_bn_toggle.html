🌐 ভাষা টগল – JavaScript দিয়ে মাল্টি-ল্যাংগুয়েজ ওয়েবপেজ (লাইন বাই লাইন)

⏱️ ১২ মিনিট পড়া ✍️ মিলন বিশ্বাস

এই টিউটোরিয়ালে আমরা শিখব কীভাবে একই ওয়েবপেজে একাধিক ভাষার কন্টেন্ট রাখা যায় এবং একটি টগল বাটন দিয়ে ব্যবহারকারী নিজের পছন্দের ভাষা বেছে নিতে পারেন। প্রতিটি লাইনের কাজ বাংলায় ব্যাখ্যা করা হবে, তাই আপনি যদি একদম নতুন হন, তবুও সব বুঝতে পারবেন।

⚡ এই পেজটিই একটি লাইভ ডেমো!
উপরের বাংলা | English | हिंदी বাটনে ক্লিক করে দেখুন।

🧱 ১. HTML – তিনটি আলাদা কন্টেইনার

প্রথমে আমরা প্রতিটি ভাষার জন্য আলাদা <div> বানাবো। প্রতিটি div-কে একটি নির্দিষ্ট ক্লাস দেব—যেমন lang-bn, lang-en, lang-hi।

<body>
  <div class="lang-bn">
    <h1>বাংলা শিরোনাম</h1>
    <p>এটি বাংলা কন্টেন্ট</p>
  </div>

  <div class="lang-en">
    <h1>English Title</h1>
    <p>This is English content</p>
  </div>

  <div class="lang-hi">
    <h1>हिंदी शीर्षक</h1>
    <p>यह हिंदी कंटेंट है</p>
  </div>
</body>
🔍 ব্যাখ্যা:
• তিনটি ডিভ একসাথে রাখা হয়েছে। কিন্তু ব্রাউজারে একসাথে সব দেখা যাবে না—আমরা CSS দিয়ে নির্ধারণ করব কোন ভাষাটি দেখাবে।
• ক্লাসের নাম যেকোনো কিছু হতে পারে, তবে অর্থপূর্ণ রাখাই ভালো।

🎨 ২. CSS – ভাষা অনুযায়ী দেখানো/লুকানো

<body> ট্যাগে একটি ক্লাস দেব যা নির্ধারণ করবে কোন ভাষা চালু আছে (যেমন class="bn")। তার ভিত্তিতে CSS দিয়ে প্রাসঙ্গিক div দেখাবো আর বাকি গুলো লুকাবো।

/* ডিফল্ট: শুধু বাংলা দেখাবে */
.lang-bn { display: block; }
.lang-en { display: none; }
.lang-hi { display: none; }

/* যখন body-তে 'en' ক্লাস থাকবে */
body.en .lang-bn { display: none; }
body.en .lang-en { display: block; }
body.en .lang-hi { display: none; }

/* যখন body-তে 'hi' ক্লাস থাকবে */
body.hi .lang-bn { display: none; }
body.hi .lang-en { display: none; }
body.hi .lang-hi { display: block; }
🔍 ব্যাখ্যা:
• body.en .lang-en – এটি সিলেক্টর মানে “body যার ক্লাস 'en', তার ভেতরের .lang-en ক্লাসের div”।
• display: none দিয়ে লুকানো হয়, display: block দিয়ে দেখানো।
• আমরা ডিফল্ট হিসেবে বাংলা দেখাতে চাই, তাই শুরুতেই .lang-bn ব্লক আর বাকি গুলো none।

🖱️ ৩. HTML বাটন – ভাষা পরিবর্তনের সুইচ

তিনটি বাটন দরকার। প্রতিটি বাটনে data-lang অ্যাট্রিবিউট দিয়ে বোঝাবো এটি কোন ভাষার জন্য।

<button class="lang-btn" data-lang="bn">বাংলা</button>
<button class="lang-btn" data-lang="en">English</button>
<button class="lang-btn" data-lang="hi">हिंदी</button>
🔍 ব্যাখ্যা:
• data-lang একটি কাস্টম ডেটা অ্যাট্রিবিউট। JavaScript দিয়ে আমরা এর মান পড়তে পারব।
• আমরা চাইলে বাটনের ভেতরে ইমোজি বা আইকনও দিতে পারি।

⚙️ ৪. জাভাস্ক্রিপ্ট – ক্লিক ইভেন্ট, ক্লাস পরিবর্তন ও লোকাল স্টোরেজ

এবার প্রাণ ঢালবো জাভাস্ক্রিপ্ট দিয়ে। যখন কেউ বাটনে ক্লিক করবে, আমরা body-র ক্লাস পরিবর্তন করব এবং পছন্দটি localStorage-এ সেভ করব।

<script>
  // ১. সব ভাষার বাটন ধরি
  const langBtns = document.querySelectorAll('.lang-btn');

  // ২. প্রতিটি বাটনে ক্লিক ইভেন্ট লাগাই
  langBtns.forEach(btn => {
    btn.addEventListener('click', () => {
      const lang = btn.getAttribute('data-lang'); // 'bn', 'en', 'hi'

      // ৩. বর্তমান সব ভাষার ক্লাস সরিয়ে নতুনটি যোগ করি
      document.body.classList.remove('bn', 'en', 'hi');
      document.body.classList.add(lang);

      // ৪.  আপডেট করি
      document.documentElement.lang = lang;

      // ৫. অ্যাক্টিভ বাটন হাইলাইট করি
      langBtns.forEach(b => b.classList.remove('active'));
      btn.classList.add('active');

      // ৬. পছন্দ localStorage-এ জমা রাখি
      localStorage.setItem('blogLang', lang);
    });
  });

  // ৭. পেজ লোডে পূর্বের পছন্দ ফিরিয়ে আনি
  const savedLang = localStorage.getItem('blogLang');
  if (savedLang) {
    document.body.classList.remove('bn', 'en', 'hi');
    document.body.classList.add(savedLang);
    document.documentElement.lang = savedLang;
    // সংশ্লিষ্ট বাটনকে active করি
    document.querySelector(`.lang-btn[data-lang="${savedLang}"]`).classList.add('active');
  }
</script>
🔍 লাইন বাই লাইন:
• document.querySelectorAll('.lang-btn') – একই ক্লাসের সব বাটনের তালিকা আনে।
• btn.getAttribute('data-lang') – বাটনের ভেতরে রাখা ভাষার কোড পড়ে।
• document.body.classList.remove('bn','en','hi') – আগের ভাষার ক্লাস সরায় (তিনটাই সরালে কোনো সমস্যা নেই) — এতে dark ক্লাস অক্ষুণ্ন থাকে।
• document.body.classList.add(lang) – নতুন ভাষার ক্লাস যোগ করে।
• document.documentElement.lang = lang – পেজের প্রাথমিক ভাষাও আপডেট হয়।
• classList.toggle('active') বা add/remove – বাটনের স্টাইল বদলাতে।
• localStorage.setItem('blogLang', lang) – ব্রাউজারের স্থায়ী স্টোরেজে ভ্যালু সেভ করে, যাতে পরেরবার পেজ ওপেন করলে আগের পছন্দ পাওয়া যায়।
• শেষ অংশে localStorage.getItem('blogLang') দিয়ে চেক করে আগের পছন্দ লোড করছি।

🌐 Language Toggle – Multilingual Webpage with JavaScript (Line by Line)

⏱️ 12 min read ✍️ Milan Biswas

In this tutorial we'll learn how to keep content in multiple languages on a single webpage and let users switch between them using a toggle button. Every single line of code is explained, so even absolute beginners can follow along.

⚡ This page itself is a live demo!
Try clicking the বাংলা | English | हिंदी buttons above.

🧱 1. HTML – Three Separate Containers

First we create a separate <div> for each language, giving each a distinct class like lang-bn, lang-en, lang-hi.

<body>
  <div class="lang-bn">
    <h1>Bangla Title</h1>
    <p>Bangla content</p>
  </div>
  <div class="lang-en">
    <h1>English Title</h1>
    <p>English content</p>
  </div>
  <div class="lang-hi">
    <h1>Hindi Title</h1>
    <p>Hindi content</p>
  </div>
</body>
🔍 Explanation:
• The three divs are siblings. We'll use CSS to decide which one is visible.
• The class names can be anything meaningful.

🎨 2. CSS – Show/Hide Based on Body Class

We'll add a class to the <body> (e.g., class="en") and use CSS combinators to hide or show the appropriate div.

/* Default: show Bangla only */
.lang-bn { display: block; }
.lang-en { display: none; }
.lang-hi { display: none; }

/* When body has class 'en' */
body.en .lang-bn { display: none; }
body.en .lang-en { display: block; }
body.en .lang-hi { display: none; }

/* When body has class 'hi' */
body.hi .lang-bn { display: none; }
body.hi .lang-en { display: none; }
body.hi .lang-hi { display: block; }
🔍 Explanation:
• `body.en .lang-en` targets the `.lang-en` div only when the body has the `en` class.
• `display: none` hides the element completely.

🖱️ 3. HTML Buttons – The Language Switcher

We need three buttons, each with a `data-lang` attribute to identify which language it controls.

<button class="lang-btn" data-lang="bn">বাংলা</button>
<button class="lang-btn" data-lang="en">English</button>
<button class="lang-btn" data-lang="hi">हिंदी</button>
🔍 Explanation:
• `data-lang` is a custom data attribute that JavaScript can read easily using `getAttribute` or `dataset`.

⚙️ 4. JavaScript – Click Handling, Class Toggle & LocalStorage

When a button is clicked, we remove all previous language classes from the body, add the new one, update active button style, and save the preference.

<script>
  const langBtns = document.querySelectorAll('.lang-btn');
  langBtns.forEach(btn => {
    btn.addEventListener('click', () => {
      const lang = btn.getAttribute('data-lang'); // 'bn', 'en', 'hi'
      document.body.classList.remove('bn', 'en', 'hi');
      document.body.classList.add(lang);
      document.documentElement.lang = lang;
      langBtns.forEach(b => b.classList.remove('active'));
      btn.classList.add('active');
      localStorage.setItem('blogLang', lang);
    });
  });

  const savedLang = localStorage.getItem('blogLang');
  if (savedLang) {
    document.body.classList.remove('bn', 'en', 'hi');
    document.body.classList.add(savedLang);
    document.documentElement.lang = savedLang;
    document.querySelector(`.lang-btn[data-lang="${savedLang}"]`).classList.add('active');
  }
</script>
🔍 Line‑by‑line explanation:
• `querySelectorAll` grabs all buttons.
• `getAttribute('data-lang')` reads the language code.
• `classList.remove` / `classList.add` safely swap classes without touching other classes (like `dark`).
• `document.documentElement.lang = lang` updates the page language for screen readers.
• `localStorage.setItem` saves the preference across sessions.
• On page load, we restore the saved language.

💡 Real‑World Tips

  • Don't replace classes: In the simple version we used `body.className = lang`. In production, use `classList` to avoid wiping out other classes (like `dark`).
  • Accessibility: Add a `lang` attribute to each language div and ensure the buttons are keyboard‑accessible.
  • URL updates: Use `history.pushState` to reflect the language in the URL without reloading.
  • Structured translations: For larger sites, keep translations in a JSON file rather than duplicated HTML.

🧱 1. HTML – तीन अलग-अलग कंटेनर

  </div>
</body>
🔍 व्याख्या:
• तीनों डिव साथ-साथ हैं। CSS के ज़रिए हम तय करेंगे कि कौन-सी भाषा दिखे।
• क्लास के नाम कुछ भी हो सकते हैं।

🎨 2. CSS – भाषा के अनुसार दिखाना/छुपाना

<body> पर एक क्लास लगाएँगे (जैसे class="en") और उसी के आधार पर CSS कॉम्बिनेटर से सही डिव दिखाएँगे।

/* डिफ़ॉल्ट: सिर्फ़ बंगाली दिखे */
.lang-bn { display: block; }
.lang-en { display: none; }
.lang-hi { display: none; }

/* जब body में 'en' क्लास हो */
body.en .lang-bn { display: none; }
body.en .lang-en { display: block; }
body.en .lang-hi { display: none; }

/* जब body में 'hi' क्लास हो */
body.hi .lang-bn { display: none; }
body.hi .lang-en { display: none; }
body.hi .lang-hi { display: block; }
🔍 व्याख्या:
• body.en .lang-en – यह सेलेक्टर तभी लागू होता है जब body पर en क्लास हो।
• display: none एलिमेंट को पूरी तरह छुपा देता है।

🖱️ 3. HTML बटन – भाषा बदलने का स्विच

तीन बटन चाहिए, हर बटन में data-lang एट्रिब्यूट देंगे ताकि पता चले यह किस भाषा का है।

<button class="lang-btn" data-lang="bn">বাংলা</button>
<button class="lang-btn" data-lang="en">English</button>
<button class="lang-btn" data-lang="hi">हिंदी</button>
🔍 व्याख्या:
• data-lang एक कस्टम डेटा एट्रिब्यूट है, जिसे JavaScript आसानी से पढ़ सकता है।

⚙️ 4. जावास्क्रिप्ट – क्लिक इवेंट, क्लास बदलना और localStorage

बटन पर क्लिक होने पर हम body की सारी भाषा क्लास हटाकर नई क्लास जोड़ेंगे, एक्टिव बटन हाइलाइट करेंगे और पसंद को सेव करेंगे।

<script>
  const langBtns = document.querySelectorAll('.lang-btn');
  langBtns.forEach(btn => {
    btn.addEventListener('click', () => {
      const lang = btn.getAttribute('data-lang');
      document.body.classList.remove('bn', 'en', 'hi');
      document.body.classList.add(lang);
      document.documentElement.lang = lang;
      langBtns.forEach(b => b.classList.remove('active'));
      btn.classList.add('active');
      localStorage.setItem('blogLang', lang);
    });
  });

  const savedLang = localStorage.getItem('blogLang');
  if (savedLang) {
    document.body.classList.remove('bn', 'en', 'hi');
    document.body.classList.add(savedLang);
    document.documentElement.lang = savedLang;
    document.querySelector(`.lang-btn[data-lang="${savedLang}"]`).classList.add('active');
  }
</script>
🔍 लाइन-दर-लाइन:
• querySelectorAll सभी बटन लाता है।
• classList.remove / add सिर्फ़ भाषा की क्लास हटाता/जोड़ता है, बाकी क्लास (जैसे dark) को नहीं छूता।
• document.documentElement.lang = lang पेज की प्राथमिक भाषा भी अपडेट करता है।
• localStorage.setItem पसंद को ब्राउज़र में सेव करता है।
• पेज लोड पर getItem से पिछली पसंद वापस लाते हैं।

🎯 पूरा कोड (कॉपी-पेस्ट करें)

<!DOCTYPE html>

  body.hi .lang-bn { display: none; }
  body.hi .lang-hi { display: block; }

💡 असली प्रोजेक्ट के लिए सुझाव

  • क्लास रीसेट न करें: सरल उदाहरण में body.className = lang इस्तेमाल हुआ है, जो बाकी क्लास हटा सकता है। बेहतर है classList.remove/add करें।
  • ऐक्सेसिबिलिटी: हर भाषा के डिव पर lang एट्रिब्यूट लगाएँ और बटन कीबोर्ड से चलने लायक हों।
  • URL अपडेट: history.pushState से बिना रीलोड भाषा बदलने पर URL भी बदल सकते हैं।
  • अनुवाद फ़ाइल: बड़ी साइटों के लिए JSON फ़ाइल में अनुवाद रखना बेहतर है।
📢 अंतिम शब्द: अब आप जान गए हैं कि भाषा टॉगल कैसे बनाया जाता है। ऊपर दिए बटन पर क्लिक करके इस पेज पर ही आज़माइए। कोई सवाल हो तो कमेंट करें।
