🚀 টিউটোরিয়াল 🚀 Tutorial

MongoDB দিয়ে আপনার ওয়েবসাইটকে স্মার্ট করা Make Your Website Smarter with MongoDB

📘 শূন্য থেকে শুরু করুন — ফ্রি ডেটাবেস, ধাপে ধাপে 📘 Start from Zero — Free Database, Step by Step

⏱️ ২০ মিনিট পড়া ⏱️ 20 min read

আপনি হয়তো ভাবছেন, "ওয়েবসাইটের ডেটা কোথায় থাকে?" উত্তরটা হলো—একটি ডেটাবেসে। আর MongoDB হলো এমন একটি ডেটাবেস যা আপনার ওয়েবসাইটের সব তথ্য (ছাত্রের নাম, নোটের লিংক, কুইজের প্রশ্ন) নিরাপদে সংরক্ষণ করে, এবং যখনই দরকার, তা দ্রুত খুঁজে বের করে।

এই টিউটোরিয়ালে আমি দেখাব কীভাবে সম্পূর্ণ বিনামূল্যে MongoDB সেটআপ করবেন এবং আপনার প্রোজেক্টের সাথে সংযোগ স্থাপন করবেন।

You might be wondering, "Where does website data live?" The answer is — in a database. And MongoDB is a database that securely stores all your website information (student names, note links, quiz questions) and retrieves it quickly whenever needed.

In this tutorial, I'll show you how to set up MongoDB completely free and connect it to your project.

📘 অধ্যায় ১: MongoDB অ্যাকাউন্ট তৈরি করা 📘 Chapter 1: Creating a MongoDB Account

  1. আপনার ব্রাউজারে গিয়ে mongodb.com টাইপ করুন এবং এন্টার চাপুন।
  2. উপরের ডান দিকে "Try Free" বা "Start Free" বাটনে ক্লিক করুন।
  3. একটি ফর্ম খুলবে। সেখানে আপনার ইমেইল, পাসওয়ার্ড, এবং নাম দিন। (আপনি গুগল বা গিটহাব অ্যাকাউন্ট দিয়েও সাইনআপ করতে পারেন)।
  4. "Create Account" বাটনে ক্লিক করুন।
  5. আপনার ইমেইলে একটি ভেরিফিকেশন লিংক আসবে। সেই লিংকে ক্লিক করে আপনার অ্যাকাউন্ট সক্রিয় করুন।
💡 লক্ষ্য: আপনার অ্যাকাউন্ট তৈরি হয়ে গেলে, আপনি একটি ড্যাশবোর্ড দেখতে পাবেন। এখন আমরা সেখানে ক্লাস্টার তৈরি করব।
  1. Go to mongodb.com in your browser and press Enter.
  2. Click the "Try Free" or "Start Free" button in the top-right corner.
  3. A form will open. Enter your email, password, and name. (You can also sign up with Google or GitHub).
  4. Click the "Create Account" button.
  5. A verification link will be sent to your email. Click that link to activate your account.
💡 Goal: Once your account is created, you'll see a dashboard. Now we'll create a cluster there.

🏗️ অধ্যায় ২: প্রথম ডেটাবেস ক্লাস্টার তৈরি করা 🏗️ Chapter 2: Creating Your First Database Cluster

একটি ক্লাস্টার হলো আপনার ডেটাবেসের "সার্ভার"। যেখানে সব ডেটা সংরক্ষিত থাকবে। ফ্রি প্ল্যানেই একটি ছোট ক্লাস্টার তৈরি করা যায়:

  1. ড্যাশবোর্ডে "Create a Cluster" বাটনে ক্লিক করুন।
  2. তিনটি অপশন দেখাবে—M0 (Free), M2, M5। আপনাকে "M0 Free" সিলেক্ট করতে হবে।
  3. ক্লাউড প্রোভাইডার হিসেবে "AWS" এবং রিজিয়ন হিসেবে "Mumbai (ap-south-1)" সিলেক্ট করুন (এশিয়ার সবচেয়ে কাছের সার্ভার)।
⚠️ সতর্কতা: কোনো টাকা খরচ হবে না। মাঝে মাঝে পেইড ভার্সন দেখালেও, "M0 Free" অপশনটি খুঁজে বের করুন। এটি ৫১২ এমবি পর্যন্ত ফ্রি স্টোরেজ দেয়।
  1. ক্লাস্টারের একটি নাম দিন (যেমন: rs-academy-cluster) এবং "Create Cluster" ক্লিক করুন।
  2. ক্লাস্টার তৈরি হতে ১-২ মিনিট সময় লাগবে। ধৈর্য ধরে অপেক্ষা করুন।
✅ অভিনন্দন: আপনার ডেটাবেসের সার্ভার প্রস্তুত! এখন আমরা সেখানে ডেটা রাখার জন্য একটি "ইউজার" তৈরি করব।

A cluster is the "server" of your database where all data will be stored. You can create a small cluster on the free plan:

  1. Click the "Create a Cluster" button in the dashboard.
  2. You'll see three options — M0 (Free), M2, M5. You need to select "M0 Free".
  3. Select "AWS" as the cloud provider and "Mumbai (ap-south-1)" as the region (the closest server to Asia).
⚠️ Warning: No money will be charged. Even if paid versions appear occasionally, find the "M0 Free" option. It offers up to 512 MB of free storage.
  1. Give your cluster a name (e.g., rs-academy-cluster) and click "Create Cluster".
  2. It will take 1–2 minutes to create the cluster. Wait patiently.
✅ Congratulations: Your database server is ready! Now we'll create a "user" to store data there.

🔐 অধ্যায় ৩: ডেটাবেস ইউজার তৈরি করা 🔐 Chapter 3: Creating a Database User

ডেটাবেসে কে প্রবেশ করতে পারবে, তা নিয়ন্ত্রণ করতে একটি ইউজারনেম ও পাসওয়ার্ড তৈরি করতে হবে:

  1. ক্লাস্টারের ড্যাশবোর্ডে "Database Access" ট্যাবে ক্লিক করুন।
  2. "Add New Database User" বাটনে ক্লিক করুন।
  3. ইউজারনেম দিন (যেমন: rs_admin) এবং একটি শক্তিশালী পাসওয়ার্ড দিন।
    🔹 টিপ: মজবুত পাসওয়ার্ড জেনারেট করতে গুগলের "পাসওয়ার্ড জেনারেটর" ব্যবহার করতে পারেন।
  4. "Add User" ক্লিক করুন। এখন এই ইউজারনেম ও পাসওয়ার্ড দিয়েই আপনার অ্যাপ ডেটাবেসে সংযোগ করবে।
🔑 গুরুত্বপূর্ণ: এই পাসওয়ার্ডটি কোথাও নোট করে রাখুন। কারণ এটি আর দেখতে পাবেন না। (আমি .env ফাইলে রাখার পরামর্শ দেব)।

To control who can access the database, you need to create a username and password:

  1. Click the "Database Access" tab in the cluster dashboard.
  2. Click the "Add New Database User" button.
  3. Enter a username (e.g., rs_admin) and a strong password.
    🔹 Tip: You can use Google's "Password Generator" to create a strong password.
  4. Click "Add User". Now your app will connect to the database using this username and password.
🔑 Important: Note this password somewhere because you won't be able to see it again. (I recommend keeping it in a .env file).

🔗 অধ্যায় ৪: নেটওয়ার্ক অ্যাক্সেস কনফিগার করা 🔗 Chapter 4: Configuring Network Access

আপনার ডেটাবেস শুধু নির্দিষ্ট আইপি ঠিকানা থেকে অ্যাক্সেস করতে পারে। যেহেতু আপনি বিভিন্ন জায়গা থেকে কাজ করবেন, তাই সব আইপিকে অনুমতি দিন:

  1. "Network Access" ট্যাবে ক্লিক করুন।
  2. "Add IP Address" বাটনে ক্লিক করুন।
  3. "Allow Access from Anywhere" অপশনে ক্লিক করুন (এটি 0.0.0.0/0 আইপি অ্যাড করবে)।
⚠️ সতর্কতা: প্রোডাকশনে এটি নিরাপদ নয়, তবে শেখার উদ্দেশ্যে এবং টেস্টিংয়ের জন্য এটি ঠিক আছে। পরে চাইলে নির্দিষ্ট আইপি অ্যাড করতে পারেন।
  1. "Confirm" ক্লিক করুন।

Your database can only be accessed from specific IP addresses. Since you'll be working from different locations, allow access from all IPs:

  1. Click the "Network Access" tab.
  2. Click the "Add IP Address" button.
  3. Click the "Allow Access from Anywhere" option (this adds the IP 0.0.0.0/0).
⚠️ Warning: This is not safe for production, but for learning and testing it's okay. You can add specific IPs later if needed.
  1. Click "Confirm".

📄 অধ্যায় ৫: কানেকশন স্ট্রিং (URI) সংগ্রহ করা 📄 Chapter 5: Collecting the Connection String (URI)

এটি হলো আপনার ডেটাবেসের "ঠিকানা", যা আপনার কোডে বসালে অ্যাপটি ডেটাবেসের সাথে কথা বলতে পারবে:

  1. "Database" ট্যাবে ফিরে যান।
  2. আপনার ক্লাস্টারের নামের পাশে "Connect" বাটনে ক্লিক করুন।
  3. একটি পপআপ খুলবে—সেখানে "Drivers" অপশন সিলেক্ট করুন।
  4. "Node.js" ড্রাইভার সিলেক্ট করুন এবং ভার্সন হিসেবে "6.7 or later" রাখুন।
  5. নিচে একটি লং ইউআরএল দেখাবে। সেটি কপি করে রাখুন।
mongodb+srv://<username>:<password>@rs-academy-cluster.xxxxx.mongodb.net/?retryWrites=true&w=majority

এখানে <username> ও <password>-এর জায়গায় আপনার তৈরি করা ইউজারনেম ও পাসওয়ার্ড বসান।

🎯 ফলাফল: আপনার কাছে এখন ডেটাবেসের পুরো ঠিকানা আছে। এখন এটি আপনার প্রোজেক্টে বসানোর পালা।

This is the "address" of your database. When you put it in your code, your app can talk to the database:

  1. Go back to the "Database" tab.
  2. Click the "Connect" button next to your cluster name.
  3. A popup will open — select the "Drivers" option.
  4. Select "Node.js" as the driver and keep the version as "6.7 or later".
  5. A long URL will appear below. Copy it and keep it safe.
mongodb+srv://<username>:<password>@rs-academy-cluster.xxxxx.mongodb.net/?retryWrites=true&w=majority

Replace <username> and <password> with the username and password you created.

🎯 Result: You now have the full database address. Now it's time to put it in your project.

⚙️ অধ্যায় ৬: প্রোজেক্টে MongoDB সংযোগ স্থাপন ⚙️ Chapter 6: Connecting MongoDB to Your Project

এখন আপনার ওয়েবসাইটের প্রোজেক্ট ফোল্ডারে গিয়ে MongoDB-কে কাজে লাগান:

⏳ ৬.১: প্রয়োজনীয় প্যাকেজ ইনস্টল করুন

আপনার টার্মিনালে (Termux/কমান্ড প্রম্পট) নিচের কমান্ড দিন:

npm install mongoose dotenv

📁 ৬.২: একটি .env ফাইল তৈরি করুন

আপনার প্রোজেক্টের রুট ফোল্ডারে .env নামে একটি ফাইল তৈরি করুন এবং তাতে এই লাইনটি লিখুন:

MONGO_URI=মঙ্গোডিবির_পুরো_ঠিকানা_যা_কপি_করেছেন
PORT=10000
JWT_SECRET=আপনার_ইচ্ছামতো_সিক্রেট_কী
💡 মনে রাখবেন: MONGO_URI-তে আপনার সেই কানেকশন স্ট্রিংটি বসবে যেখানে ইউজারনেম ও পাসওয়ার্ড দেওয়া আছে।

🧩 ৬.৩: ডেটাবেস সংযোগের ফাইল তৈরি করুন

config/db.js নামে একটি ফাইল তৈরি করে নিচের কোডটি লিখুন:

const mongoose = require('mongoose');
require('dotenv').config();

const connectDB = async () => {
  try {
    await mongoose.connect(process.env.MONGO_URI);
    console.log('✅ MongoDB সংযুক্ত হয়েছে!');
  } catch (error) {
    console.error('❌ সংযোগ ব্যর্থ:', error.message);
    process.exit(1);
  }
};

module.exports = connectDB;

🚀 ৬.৪: মূল সার্ভার ফাইলে সংযোগ দিন

server.js ফাইলের শুরুতে এই লাইনগুলো যোগ করুন:

const connectDB = require('./config/db');

// ডেটাবেস সংযোগ
connectDB();

▶️ ৬.৫: সার্ভার চালান

node server.js কমান্ড দিন। যদি টার্মিনালে ✅ MongoDB সংযুক্ত হয়েছে! লেখা দেখায়, তাহলে বুঝবেন সব ঠিকঠাক কাজ করছে!

Now go to your website's project folder and put MongoDB to work:

⏳ 6.1: Install Required Packages

Run the following command in your terminal (Termux/command prompt):

npm install mongoose dotenv

📁 6.2: Create a .env File

Create a file named .env in your project's root folder and write this line in it:

MONGO_URI=your_copied_mongodb_uri
PORT=10000
JWT_SECRET=any_secret_key_you_like
💡 Remember: In MONGO_URI, you need to place the connection string that includes your username and password.

🧩 6.3: Create the Database Connection File

Create a file named config/db.js and write the following code:

const mongoose = require('mongoose');
require('dotenv').config();

const connectDB = async () => {
  try {
    await mongoose.connect(process.env.MONGO_URI);
    console.log('✅ MongoDB connected!');
  } catch (error) {
    console.error('❌ Connection failed:', error.message);
    process.exit(1);
  }
};

module.exports = connectDB;

🚀 6.4: Add the Connection to Your Main Server File

At the beginning of your server.js file, add these lines:

const connectDB = require('./config/db');

// Connect to database
connectDB();

▶️ 6.5: Run the Server

Run the command node server.js. If you see ✅ MongoDB connected! in the terminal, everything is working perfectly!

🧭 উপসংহার 🧭 Conclusion

এখন আপনি MongoDB-এর অ্যাকাউন্ট তৈরি, ক্লাস্টার সেটআপ এবং প্রোজেক্টে সংযোগ স্থাপন—সবকিছু শিখে ফেলেছেন। আপনি আপনার ওয়েবসাইটকে একটি শক্তিশালী ডেটাবেস দিয়ে সজ্জিত করেছেন। এখন আপনি চাইলে ছাত্রদের তথ্য, নোট, কুইজ—সবকিছু এই ডেটাবেসে সংরক্ষণ করতে পারবেন। আর সবচেয়ে ভালো কথা—এটি সম্পূর্ণ ফ্রি!

💡 মনে রাখবেন: ডেটাবেস শুধু একটা টুল। এর আসল ব্যবহার শুরু হয় যখন আপনি এতে ডেটা রাখতে এবং খুঁজতে শিখবেন। পরবর্তী টিউটোরিয়ালে আমি দেখাব কীভাবে এই ডেটাবেসে ছাত্রদের তথ্য সংরক্ষণ করা যায় এবং তা থেকে প্রোজেক্টে দেখানো যায়।

You have now learned how to create a MongoDB account, set up a cluster, and connect it to your project. You have equipped your website with a powerful database. Now you can store student information, notes, quizzes — everything in this database. And the best part — it's completely free!
