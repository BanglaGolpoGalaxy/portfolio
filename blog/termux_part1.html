ভূমিকা: কেন এই সিরিজ?

স্বাগতম! আপনি যদি এই পৃষ্ঠায় এসে থাকেন, তাহলে নিশ্চয়ই আপনার হাতে একটি অ্যান্ড্রয়েড ফোন আছে আর মাথায় একটা স্বপ্ন—কিছু একটা শিখবেন, কিছু একটা বানাবেন। কিন্তু ল্যাপটপ নেই, কম্পিউটার নেই, অথবা দামি কোর্স করার সামর্থ্য নেই।

আমি আপনাকে স্বাগত জানাই এক নতুন সম্ভাবনার জগতে। এই জগতে আপনার ফোনটাই হয়ে উঠবে আপনার সবচেয়ে শক্তিশালী সার্ভার। Termux নামের একটি জাদুর বাক্স খুলে আমরা সেই ফোন দিয়েই তৈরি করব বাস্তব জিনিস—ওয়েবসাইটের ব্যাকএন্ড, API, ডাটাবেস, এমনকি নিজস্ব ক্লাউড স্টোরেজ!

🎯 এই সিরিজ যাদের জন্য

  • ফ্রিল্যান্সার ও জব সিকার: HTML, CSS, JS জানেন কিন্তু ব্যাকএন্ড শেখার জন্য ল্যাপটপ নেই? Termux দিয়ে Node.js, Express, API শিখে ফেলুন আর পোর্টফোলিও তৈরি করুন।
  • ক্ষুদ্র ব্যবসায়ী: আপনার ফার্মেসি বা মুদি দোকানের জন্য বিলিং ও স্টক ম্যানেজমেন্ট সিস্টেম নিজেই বানাতে চান, একদম ফ্রিতে? এই সিরিজ আপনাকে সেই ক্ষমতা দেবে।
  • শিক্ষার্থী ও টেক এনথুসিয়াস্ট: মোবাইল দিয়ে কী কী করা যায় জানতে চান? Termux আপনার জন্য এক বিশাল খেলার মাঠ। পকেট লিনাক্সের রাজ্যে স্বাগতম!
  • কন্টেন্ট ক্রিয়েটর: বাংলায় Termux শেখার ভালো রিসোর্স খুঁজছেন? এই সিরিজ থেকে শিখে নিজেও তৈরি করতে পারেন দারুণ কন্টেন্ট।

১. Termux ইন্সটল করা

Termux পাওয়া যায় F-Droid স্টোর থেকে। প্লে স্টোরের ভার্সনটি পুরোনো, তাই F-Droid থেকেই নেওয়া ভালো।

  1. মোবাইলের ব্রাউজার থেকে f-droid.org খোলো।
  2. সার্চ দাও "Termux"।
  3. সর্বশেষ ভার্সন ডাউনলোড করে ইন্সটল করো।
  4. ইন্সটলের পর অ্যাপটি ওপেন করো। দেখবে সাদা-কালো একটা টার্মিনাল, যেখানে কিছু লেখা থাকবে।

এটাই Termux! এখন থেকে এখানেই আমরা সব জাদু দেখাব।

২. প্রথম আপডেট ও জরুরি টুলস ইন্সটল

Termux খোলার সাথে সাথেই নিচের কমান্ডটি দাও:

pkg update && pkg upgrade -y

pkg হলো Termux-এর প্যাকেজ ম্যানেজার। এটা অ্যাপ স্টোরের মতো। update আর upgrade একসাথে দিয়ে আমরা সবকিছু হালনাগাদ করে নিচ্ছি।

এখন কিছু দরকারি প্রোগ্রাম ইন্সটল করি:

pkg install nodejs micro -y

nodejs: জাভাস্ক্রিপ্ট রান করার ইঞ্জিন। এটা দিয়েই আমরা সার্ভার বানাব। micro: একটা টেক্সট এডিটর (মোবাইলের ভেতরের Notepad), যা মোবাইলের টাচ স্ক্রিনে দারুণ কাজ করে।

৩. টার্মিনালে চলাফেরার বেসিক কমান্ড

টার্মিনালে কাজ মানেই কমান্ড টাইপ করা। কিছু কমান্ড শিখে নিলে সারা জীবন কাজে লাগবে।

কমান্ডকাজ
pwdএখন কোন ফোল্ডারে আছি, তা দেখায়।
lsওই ফোল্ডারের ভেতরের ফাইল-ফোল্ডারের তালিকা দেখায়। (LS = List)
mkdir ফোল্ডারের_নামনতুন খালি ফোল্ডার তৈরি করে। (MKDIR = Make Directory)
cd ফোল্ডারের_নামওই ফোল্ডারের ভেতরে ঢোকা। (CD = Change Directory)
cd ..এক ধাপ উপরে (প্যারেন্ট ফোল্ডারে) ফিরে যাওয়া।
touch ফাইলের_নামএকটা নতুন খালি ফাইল তৈরি করে।

প্রথম প্র্যাকটিস:

mkdir my-first-project
cd my-first-project
pwd

তুমি এখন my-first-project ফোল্ডারের ভেতরে আছো।

৪. প্রথম ফাইল তৈরি ও কন্টেন্ট দেখা

এখন আমরা এই ফোল্ডারের ভেতরে একটা ফাইল বানাই:

touch hello.txt

এটা সম্পূর্ণ খালি ফাইল। এবার এতে কিছু লিখি। আমরা micro এডিটর ব্যবহার করব, যা আগে ইন্সটল করেছি।

micro hello.txt

এবার মাইক্রো এডিটর ওপেন হবে। উপরে টাইপ করো:

এই তো আমার Termux-এ প্রথম ফাইল!

সেভ করো: Ctrl + S (ভলিউম ডাউন + S চেপেও করতে পারো)
বের হও: Ctrl + Q

এখন ফাইলটির ভেতরে কী লিখেছ, তা দেখার জন্য:

cat hello.txt

পর্দায় তোমার লেখা লাইনটি দেখাবে। cat মানে কনক্যাটিনেট, কিন্তু আমরা সহজভাবে বলি "ফাইল পড়া"।

৫. ফোল্ডার কাঠামো (প্রজেক্টের জন্য আদর্শ)

একটা বাস্তব প্রজেক্টে ফাইল-ফোল্ডার এলোমেলো থাকলে সমস্যা হয়। চলো, আমরা একটা সুন্দর ফোল্ডার স্ট্রাকচার বানাই:

mkdir -p shop-api/public shop-api/data

mkdir -p একবারে ভেতরের সব ফোল্ডার তৈরি করবে। এখানে shop-api-র ভেতর public (ওয়েবসাইটের ফাইল রাখার জন্য) আর data (ডেটা ফাইল রাখার জন্য) ফোল্ডার তৈরি হলো। ls shop-api দিয়ে দেখো।

৬. আজকের শেষ কাজ: প্রথম Node.js স্ক্রিপ্ট

আমরা এখন Node.js-এর সাথে একটু পরিচিত হই। my-first-project-এ ফিরে আসি:

cd ~/my-first-project

একটা ফাইল বানাই app.js:

micro app.js

ভেতরে লিখো:

console.log("আমার Termux জয়ন হয়ে গেছে! Node.js চলছে!");

রান করো:

node app.js

তুমি কনসোলে সেই লাইনটি দেখতে পাবে। এটাই হলো তোমার লেখা প্রথম জাভাস্ক্রিপ্ট কোড, যা Node.js চালালো!

🎯 পর্ব ১-এর শেষ কথা

আজ আমরা যা শিখলাম:

  • Termux হলো মোবাইলের ভেতরের লিনাক্স কম্পিউটার।
  • pkg দিয়ে জিনিস ইন্সটল করা।
  • pwd, ls, mkdir, cd, touch, cat কমান্ড।
  • micro দিয়ে ফাইল এডিট করা।
  • node দিয়ে জাভাস্ক্রিপ্ট চালানো।

এগুলোই হলো ভিত। আজকের এই ছোট্ট শেখাটাই আগামী দিনে বড় বড় প্রজেক্টের ভিত হবে।

পরবর্তী পর্বে: আমরা Express.js ইন্সটল করে একটি লাইভ API বানাব, যেখানে ব্রাউজার থেকে প্রোডাক্ট লিস্ট দেখতে পারব। সেটাই হবে দোকান ম্যানেজমেন্ট সিস্টেমের প্রথম ইট।

ততক্ষণ পর্যন্ত এই কমান্ডগুলো প্র্যাকটিস করো। কোনো প্রশ্ন থাকলে কমেন্টে জানিও। শুভ কোডিং! 😊📱✨

1. Install Termux

Get the latest Termux from F-Droid.

  1. Open f-droid.org in your browser.
  2. Search "Termux" and download the latest APK.
  3. Install and open. A white-and-black terminal will appear.

That's Termux! Now we'll do all our magic here.

2. First Update & Install Tools

pkg update && pkg upgrade -y

Then install essential packages:

pkg install nodejs micro -y

nodejs runs JavaScript; micro is a touch-friendly text editor.

3. Basic Navigation Commands

CommandWhat it does
pwdShow current folder
lsList files & folders
mkdir <name>Create a folder
cd <folder>Enter folder
cd ..Go up one level
touch <file>Create empty file

First practice:

mkdir my-first-project
cd my-first-project
pwd

You are now inside my-first-project.

4. Create & View First File

touch hello.txt
micro hello.txt

Write: This is my first Termux file!
Save: Ctrl+S, Exit: Ctrl+Q.
To view: cat hello.txt

5. Build Folder Structure

mkdir -p shop-api/public shop-api/data

6. First Node.js Script

cd ~/my-first-project
micro app.js
console.log("My Termux journey has begun! Node.js is running!");

Run: node app.js
