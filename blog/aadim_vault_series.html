🧭 আমরা কী করতে চলেছি? (এই সিরিজের রোডম্যাপ)

স্বাগতম! তুমি এমন একটা জার্নি শুরু করতে যাচ্ছ, যেখানে শুধু একটা মোবাইল ফোন দিয়েই বানিয়ে ফেলবে একটা বিশ্বজনীন ডিজিটাল ভল্ট—"আদিম ভল্ট" (AadimVault)। এটা হবে পৃথিবীর হারানো গল্প, পুরোনো স্মৃতিচিহ্ন আর বিস্মৃত ইতিহাসের ডিজিটাল ঠিকানা। ল্যাপটপ ছাড়া, শুধু অ্যান্ড্রয়েড আর ইচ্ছাশক্তি দিয়েই পুরো প্ল্যাটফর্ম বানানো যায়—এটা আমরা প্রমাণ করব।

আজ প্রথম পর্বে আমরা পুরো প্রোজেক্টের ভিত্তি বসাবো। GitHub রিপো তৈরি করব, Termux-কে আমাদের ডেভ স্টুডিও বানাব, আর প্রথম Express সার্ভার চালু করব।

🧪 "মিলান মেথড" — কেন আমরা আলাদাভাবে কাজ করব?

মোবাইলে কোড এডিট করতে গেলে ছোট ছোট অংশ বারবার বদলানো কঠিন। তাই আমরা পুরো ফাইল ডিলিট করে একবারে সম্পূর্ণ ফুল কোড বসিয়ে দেব। এতে সময় বাঁচে, এনকোডিং সমস্যা থাকে না, আর ফাইলের প্রতিটা লাইন আমাদের নিজের নিয়ন্ত্রণে থাকে। তুমি যদি কখনও দেখো বাংলা লেখা ভেঙে যাচ্ছে, তাহলে GitHub-এর অনলাইন এডিটর ব্যবহার করবে।

ধাপ ১: রিপোজিটরি তৈরি — মস্তিষ্কের বাসা

প্রথমে GitHub-এ গিয়ে aadimvault নামে একটা পাবলিক রিপো তৈরি করো। ডেসক্রিপশন দাও: Adim Vault (AadimVault): A Reliquium — Where Forgotten Objects Live Again।

ধাপ ২: Termux-কে ডেভ স্টুডিও বানানো

Termux ওপেন করে নিচের কমান্ড দাও। এতে তোমার ফোনের ভেতরেই প্রোজেক্ট ফোল্ডার তৈরি হবে।

cd ~/storage/shared/
git clone https://github.com/BanglaGolpoGalaxy/aadimvault.git
cd aadimvault

কী হলো এখানে? git clone মানে গিটহাবের পুরো ফোল্ডারটা নিজের ফোনে নামিয়ে আনা। cd aadimvault দিয়ে সেই ফোল্ডারে ঢোকা হলো। এখন থেকে তুমি এই ফোল্ডারেই সব কাজ করবে।

ধাপ ৩: ফোল্ডার স্ট্রাকচার — বাড়ির নকশা

একটা বাড়ি বানানোর আগে যেমন নকশা আঁকতে হয়, কোডের জগতেও তেমনি ফোল্ডার আর ফাইলের নাম ঠিক করা হয়। নিচের কাঠামোটা আমরা তৈরি করব।

aadimvault/
├── server.js           → API সার্ভার
├── package.json        → প্রোজেক্টের তথ্য ও ডিপেন্ডেন্সি
├── database/db.js      → SQLite ডাটাবেস লজিক
├── middleware/auth.js  → JWT গার্ড
├── routes/auth.js      → লগইন/রেজিস্টার API
├── routes/products.js  → প্রোডাক্ট CRUD API
├── uploads/            → ছবি জমা রাখার জায়গা
└── public/             → ফ্রন্টএন্ড (HTML, CSS, JS)
    ├── index.html
    ├── css/style.css
    └── js/main.js
mkdir -p database middleware routes uploads public/css public/js public/images
touch server.js .env .env.example .gitignore README.md BLUEPRINT.md
touch database/db.js middleware/auth.js routes/auth.js routes/products.js

কেন এমন করলাম? mkdir -p দিয়ে একসাথে সব ফোল্ডার বানিয়ে ফেললাম। touch দিয়ে ফাঁকা ফাইল তৈরি করলাম, যেগুলো পরে আমরা কোড দিয়ে ভরব।

ধাপ ৪: বয়লারপ্লেট কোড — হাড়গোড় তৈরি

এখন আমরা কিছু ফাইলে ন্যূনতম কোড বসাব। এতে সার্ভার চালু করলেই অন্তত কিছু দেখা যাবে।

🔹 server.js

এটাই আমাদের প্রধান সার্ভার ফাইল। নিচের কোড বুঝে বুঝে লিখো।

// dotenv প্যাকেজ – .env ফাইলের সিক্রেট পড়ার জন্য
require('dotenv').config();
// Express ফ্রেমওয়ার্ক লোড
const express = require('express');
// cors – অন্য ডোমেইন থেকে রিকোয়েস্ট আসতে দেবে
const cors = require('cors');
// path – ফাইলের সঠিক ঠিকানা বানাতে
const path = require('path');

const app = express();
// পোর্ট: .env ফাইলে না থাকলে 3000
const PORT = process.env.PORT || 3000;

// Middleware
app.use(cors());
app.use(express.json());

// public ফোল্ডারকে সরাসরি ব্রাউজারে দেখার জন্য
app.use(express.static(path.join(__dirname, 'public')));
// uploads ফোল্ডারের ছবিগুলোও সরাসরি দেখা যাবে
app.use('/uploads', express.static(path.join(__dirname, 'uploads')));

// যেকোনো রিকোয়েস্টে প্রথমেই index.html দেখাবে
app.get('/', (req, res) => {
  res.sendFile(path.join(__dirname, 'public', 'index.html'));
});

// সার্ভার চালু
app.listen(PORT, () => {
  console.log(`[Adim Vault] Server running on http://localhost:${PORT}`);
});

কী হচ্ছে এখানে? express() দিয়ে একটা সার্ভার অ্যাপ তৈরি হলো। app.use(cors()) না দিলে ফ্রন্টএন্ড আর ব্যাকএন্ড আলাদা ডোমেইনে থাকলে ব্লক করবে। app.use(express.static(...)) দিয়ে আমরা বলে দিচ্ছি যে public আর uploads ফোল্ডারের ফাইলগুলো সরাসরি ব্রাউজার থেকে দেখা যাবে।

🚨 সম্ভাব্য সমস্যা: Termux-এ কখনো EPERM এরর আসতে পারে। এর মানে Termux সিমলিংক তৈরি করতে পারছে না। সমাধান: প্রোজেক্ট ফোল্ডার Termux-এর নিজস্ব হোম ডিরেক্টরিতে (~/) সরিয়ে নাও, শেয়ার্ড স্টোরেজে রাখবে না।

ধাপ ৬: প্রথম সার্ভার চালু — প্রাণ প্রতিষ্ঠা

node server.js

আউটপুট:

[Adim Vault] Server running on http://localhost:3000

মোবাইলের ব্রাউজারে গিয়ে http://localhost:3000 লিখলে তুমি দেখবে তোমার প্রথম পেজ—"আদিম ভল্ট"। এই মুহূর্তে পুরো প্রোজেক্টের কঙ্কাল দাঁড়িয়ে গেছে।

🐢 কেন ধীর? Termux আর sql.js মোবাইলে একটু সময় নেয়। কিন্তু চিন্তা নেই, ডেভেলপমেন্টে এটা স্বাভাবিক। লাইভ সার্ভারে গেলে গতি বেড়ে যাবে।

🧪 The "Milan Method" — Why We Work Differently

On mobile, editing small portions of a file repeatedly is difficult. So we delete the entire file and paste the complete, full code at once. This saves time, avoids encoding issues, and keeps every line under our own control. If you ever see Bengali text breaking, use GitHub's online editor.

Step 1: Create the Repository — Home for the Brain

First, create a public repo on GitHub called aadimvault. Give it the description: Adim Vault (AadimVault): A Reliquium — Where Forgotten Objects Live Again.

Step 2: Turn Termux into a Dev Studio

Open Termux and enter these commands. Your project folder will be created right inside your phone.

cd ~/storage/shared/
git clone https://github.com/BanglaGolpoGalaxy/aadimvault.git
cd aadimvault

What happened? git clone downloads the entire repository to your phone. cd aadimvault takes you into that folder. From now on, you'll do all your work here.

🚨 Possible Issue: Sometimes Termux throws an EPERM error. This means Termux can't create symlinks. Solution: Move your project folder to Termux's own home directory (~/), not shared storage.

Step 6: Run the First Server — Breathing Life
