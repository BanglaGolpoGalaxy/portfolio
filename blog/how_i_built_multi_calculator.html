🧮 কিভাবে আমি একটি মাল্টি-ক্যালকুলেটর টুল বানালাম

📅 ২৬ এপ্রিল, ২০২৬ ⏱️ পড়তে ৬ মিনিট ✍️ মিলন বিশ্বাস

আমি যখন প্রথম ওয়েব ডেভেলপমেন্ট শেখা শুরু করি, তখন ভাবতাম শুধু দেখতে সুন্দর ওয়েবসাইট বানালেই হয়। কিন্তু আসল চ্যালেঞ্জ শুরু হয় যখন আমি নিজের জন্য কিছু প্র্যাকটিক্যাল টুল তৈরি করতে চাইলাম। এই ব্লগ পোস্টে আমি শেয়ার করব কিভাবে আমি একটি অল-ইন-ওয়ান মাল্টি-ক্যালকুলেটর তৈরি করেছি – যেখানে আছে সাধারণ ক্যালকুলেটর, ত্রিকোণমিতি, জ্যামিতি, ইউনিট কনভার্টার, ফুল বাজার, ইএমআই, বিএমআই – সব একসাথে!

🎯 কেন এই প্রোজেক্ট?

আমার কাছে সবসময়ই মনে হতো, একাধিক ছোট ছোট ক্যালকুলেটর টুল থাকার চেয়ে একটি বড় টুল থাকলে সেটা বেশি কার্যকরী হয়। আপনি যখন ফুল কিনতে যান, তখন ফুল বাজারের হিসাব দরকার; আবার ব্যাংকে লোন নিতে গেলে ইএমআই; শরীরের যত্ন নিতে গেলে বিএমআই। এছাড়াও দৈনন্দিন জীবনে দৈর্ঘ্য, ওজন, তাপমাত্রা কনভার্ট করতে হয়। তাই আমি সবগুলো এক জায়গায় এনে দিলাম।

🛠️ প্রযুক্তি যা ব্যবহার করেছি

  • HTML5 → কাঠামো তৈরি করতে
  • CSS3 → ডিজাইন ও ডার্ক/লাইট মোডের জন্য
  • জাভাস্ক্রিপ্ট → সব হিসাব ও ফিচারের জন্য
  • GitHub Pages → ফ্রিতে হোস্ট করতে

কোনো ব্যাকএন্ড নেই, কোনো ডাটাবেস নেই – পুরো অফলাইনে কাজ করে। শুধু HTML, CSS আর JS-ই যথেষ্ট ছিল।

📐 ক্যালকুলেটরের বিভিন্ন অংশ

১. সাধারণ ক্যালকুলেটর

সবচেয়ে ক্লাসিক পার্ট। এখানে যোগ, বিয়োগ, গুণ, ভাগ, বর্গমূল, শতকরা – সবকিছু আছে। আমি বাটনগুলোকে বাজারের ক্যালকুলেটরের মত করে সাজিয়েছি। বিশেষ করে ব্র্যাকেট ( ) [ ] { } দিয়েছি যাতে বড় এক্সপ্রেশন একসাথে করা যায়। আর ভালো লাগার জন্য + বাটনটাকে বড় করে দিয়েছি।

// ইভাল না করে নিজের সেফ ইভাল ফাংশন
function safeEval(expr) {
  let processed = expr.replace(/×/g, '*').replace(/÷/g, '/');
  return Function('"use strict";return (' + processed + ')')();
}

📌 চ্যালেঞ্জ: ইউজার যখন `eval()` ব্যবহার করে, তখন সিকিউরিটি ইস্যু হতে পারে। তাই আমি কেবল ক্যালকুলেটরের বাটন দিয়েই ইনপুট নিয়েছি, ইউজার সরাসরি স্ক্রিপ্ট দিতে পারে না।

২. ত্রিকোণমিতি

মাধ্যমিক অঙ্কের জন্য sin, cos, tan এবং তাদের ইনভার্স ফাংশন। ডিগ্রি ইনপুট নিয়ে রেডিয়ানে কনভার্ট করে জাভাস্ক্রিপ্টের Math.sin() ইত্যাদি ব্যবহার করেছি। ফলাফল দশমিক ও ভগ্নাংশ – উভয় আকারে দেখায়।

function sin(deg) {
  let rad = deg * Math.PI / 180;
  return Math.sin(rad);
}

৩. জ্যামিতি (পরিমিতি)

বর্গ, আয়তক্ষেত্র, বৃত্ত, ঘনক, গোলক, ত্রিভুজ – এদের ক্ষেত্রফল, আয়তন, কর্ণ, অতিভুজ ইত্যাদি বের করার জন্য ফর্মুলা বসিয়েছি। বিশেষ করে বিষমবাহু ত্রিভুজের ক্ষেত্রফলের জন্য হেরনের সূত্র এবং সমকোণী ত্রিভুজের জন্য পিথাগোরাসের উপপাদ্য ব্যবহার করেছি।

// হেরনের সূত্র
let s = (a+b+c)/2;
let area = Math.sqrt(s*(s-a)*(s-b)*(s-c));

৪. ইউনিট কনভার্টার

দৈর্ঘ্য (মিটার, সেমি, মিমি, কিমি, ইঞ্চি, ফুট, গজ), আয়তন (লিটার, মিলিলিটার, গ্যালন, ঘনমিটার), তাপমাত্রা (সেলসিয়াস, ফারেনহাইট, কেলভিন) এবং ওজন (কেজি, গ্রাম, পাউন্ড, আউন্স, টন) – সব এক জায়গায়। ইউজার একটি ইউনিটে মান দিলেই অন্য সব ইউনিটে ফলাফল দেখায়।

৫. ফুল বাজার ক্যালকুলেটর

আমি আগে ফুলের দোকানে কাজ করতাম। সেখানে মালামালের মোট ওজন থেকে ব্যাগ ও বর্জ্য বাদ দিয়ে পাকা ওজন বের করতে হয়। এই ক্যালকুলেটর সেই হিসাব ২ সেকেন্ডে করে দেয়।

৬. ইএমআই ও বিএমআই

ইএমআই ক্যালকুলেটর ঋণের মাসিক কিস্তি বের করে। বিএমআই ক্যালকুলেটর উচ্চতা ও ওজন থেকে শরীরের ভরসূচক নির্ণয় করে এবং কমেন্ট দেখায় (ওজন কম, স্বাভাবিক, বেশি ইত্যাদি)।

  1. একসাথে সব করার চেষ্টা করবেন না – আমি প্রথমে শুধু সাধারণ ক্যালকুলেটর বানালাম, তারপর ত্রিকোণমিতি যোগ করলাম, এরপর ইউনিট কনভার্টার। ধাপে ধাপে বাড়ালে বাগ খুঁজে পাওয়া সহজ হয়।

  4. ডার্ক/লাইট মোড দিতে CSS ভেরিয়েবল ব্যবহার করুন – সম্পূর্ণ ডিজাইন কয়েক লাইনে বদলে যায়।

🧮 How I Built a Multi-Calculator Tool

📅 April 26, 2026 ⏱️ 6 min read ✍️ Milan Biswas

When I first started learning web development, I thought building a good-looking website is enough. But the real challenge began when I wanted to create some practical tools for myself. In this blog post, I will share how I built an all-in-one multi-calculator tool – where there is a basic calculator, trigonometry, geometry, unit converter, flower market, EMI, BMI – everything together!

🎯 Why this project?

I always felt that having multiple small calculators is less efficient than one big tool. When you go to buy flowers, you need flower market calculations; when you take a loan, you need EMI; for health, you need BMI. Also in daily life, you often convert length, weight, temperature. So I brought everything into one place.

🛠️ Technologies used

  • HTML5 – structure
  • CSS3 – styling & dark/light mode
  • JavaScript – all calculations
  • GitHub Pages – free hosting

No backend, no database – everything works offline. HTML, CSS, and JS were enough.

📐 Different parts of the calculator

1. Basic Calculator

The classic part. Addition, subtraction, multiplication, division, square root, percentage – everything is there. I arranged the buttons like a market calculator. I also added brackets ( ) [ ] { } so that long expressions can be typed in one line. And I made the '+' button larger for better look.

// Safe eval without using eval()
function safeEval(expr) {
  let processed = expr.replace(/×/g, '*').replace(/÷/g, '/');
  return Function('"use strict";return (' + processed + ')')();
}

📌 Challenge: Using `eval()` can cause security issues. So I only allowed input through calculator buttons – users cannot inject scripts directly.

2. Trigonometry

For secondary level math: sin, cos, tan and their inverse functions. Input in degrees, convert to radians, then use JavaScript's Math.sin() etc. Result shown both in decimal and fraction.

function sin(deg) {
  let rad = deg * Math.PI / 180;
  return Math.sin(rad);
}

3. Geometry

Square, rectangle, circle, cube, sphere, triangle – area, volume, diagonal, hypotenuse etc. Used Heron's formula for scalene triangle and Pythagoras theorem for right triangle.

// Heron's formula
let s = (a+b+c)/2;
let area = Math.sqrt(s*(s-a)*(s-b)*(s-c));

4. Unit Converter

Length (meter, cm, mm, km, inch, foot, yard), volume (liter, mL, gallon, cubic meter), temperature (Celsius, Fahrenheit, Kelvin) and weight (kg, gram, pound, ounce, ton). Once you enter a value in one unit, all other units show the converted value automatically.

5. Flower Market Calculator

I used to work at a flower shop. There we had to deduct bag weight and waste from total weight to get net weight. This calculator does that in 2 seconds.

6. EMI & BMI

EMI calculator gives monthly loan installment. BMI calculator tells you whether you are underweight, normal, overweight or obese.

💡 Learning steps (Tips for beginners)

  1. Don't try to do everything at once – I first built the basic calculator, then added trigonometry, then unit converter. Adding step by step makes debugging easier.
  2. Use tab system – To put all calculators on one page, use tabs or dropdown. I used tab buttons so that only one panel is visible at a time.
  3. Validate user input – Handle division by zero or square root of negative numbers. Keep error handling functions.
  4. Use CSS variables for dark/light mode – The whole design changes in a few lines.
  5. Make your project live on GitHub – Best way to showcase your work. Anyone with the link can use the calculator.

🎉 What I learned

  • Security awareness regarding eval() in JavaScript
  • Arranging buttons with CSS Grid and Flexbox
  • Creating dynamic HTML elements
  • Implementing mathematical formulas in code
  • Keeping the project modular and readable

जब मैंने पहली बार web development सीखना शुरू किया, तो मैं सोचता था कि सिर्फ अच्छी दिखने वाली वेबसाइट बनाना ही काफी है। लेकिन असली चुनौती तब शुरू हुई जब मैंने अपने लिए कुछ practical tools बनाने की कोशिश की। इस blog post में मैं साझा करूँगा कि कैसे मैंने एक all-in-one multi-calculator tool बनाया - जहाँ basic calculator, trigonometry, geometry, unit converter, फूल बाजार, EMI, BMI - सब कुछ एक साथ है!

// सुरक्षित eval फ़ंक्शन

  let processed = expr.replace(/×/g, '*').replace(/÷/g, '/');
  return Function('"use strict";return (' + processed + ')')();
}

📌 चुनौती: `eval()` का उपयोग करने से सुरक्षा समस्या हो सकती है। इसलिए मैंने केवल कैलकुलेटर के बटनों से इनपुट लिया – उपयोगकर्ता सीधे script नहीं दे सकता।

2. त्रिकोणमिति

माध्यमिक गणित के लिए sin, cos, tan और उनके inverse फ़ंक्शन। डिग्री इनपुट लेकर रेडियन में बदलता हूँ, फिर JavaScript के Math.sin() आदि का उपयोग करता हूँ। परिणाम दशमलव और भिन्न दोनों में दिखाता है।

function sin(deg) {
  let rad = deg * Math.PI / 180;
  return Math.sin(rad);
}

3. ज्यामिति

वर्ग, आयत, वृत्त, घन, गोला, त्रिभुज – क्षेत्रफल, आयतन, विकर्ण, कर्ण आदि। विषमबाहु त्रिभुज के लिए हीरोन का सूत्र और समकोण त्रिभुज के लिए पाइथागोरस प्रमेय का उपयोग किया।

// हीरोन का सूत्र
let s = (a+b+c)/2;
let area = Math.sqrt(s*(s-a)*(s-b)*(s-c));

4. यूनिट कन्वर्टर

लंबाई (मीटर, सेमी, मिमी, किमी, इंच, फुट, गज), आयतन (लीटर, मिलीलीटर, गैलन, घन मीटर), तापमान (सेल्सियस, फारेनहाइट, केल्विन) और वजन (किलोग्राम, ग्राम, पाउंड, औंस, टन) – सब एक जगह। एक यूनिट में मान डालने पर बाकी सभी यूनिट में मान दिख जाता है।

5. फूल बाजार कैलकुलेटर

मैं पहले फूल की दुकान पर काम करता था। वहाँ कुल वजन से बैग और बेकार वजन निकालकर शुद्ध वजन निकालना पड़ता था। यह कैलकुलेटर 2 सेकंड में वह हिसाब कर देता है।

6. EMI और BMI

EMI कैलकुलेटर लोन की मासिक किस्त निकालता है। BMI कैलकुलेटर बताता है कि आप कम वजन, सामान्य, अधिक वजन या मोटे हैं।

💡 सीखने के चरण (शुरुआती लोगों के लिए सुझाव)

  1. एक साथ सब कुछ करने की कोशिश न करें – मैंने पहले सिर्फ basic calculator बनाया, फिर trigonometry जोड़ा, फिर unit converter। कदम दर कदम बढ़ाने से bugs ढूंढना आसान होता है।
  2. Tab system का उपयोग करें – सभी calculators को एक पेज पर रखने के लिए tabs या dropdown का उपयोग करें। मैंने tabs बटन दिए हैं ताकि एक बार में एक पैनल दिखे।
  3. User input को validate करें – शून्य से भाग या नकारात्मक संख्या का वर्गमूल संभालें। error handling फ़ंक्शन रखें।
  4. Dark/light mode के लिए CSS variables का उपयोग करें – कुछ लाइनों में पूरा design बदल जाता है।
  5. अपने project को GitHub पर live करें – अपना काम दिखाने का सबसे अच्छा तरीका। कोई भी link से calculator उपयोग कर सकता है।
