🌙 ডার্ক মোড টগল – CSS ভেরিয়েবল ও JavaScript (সবকিছু লাইন ধরে বুঝুন)

📅 ২৯ এপ্রিল, ২০২৬ ⏱️ ১০ মিনিট পড়া ✍️ মিলন বিশ্বাস

এই টিউটোরিয়ালে আমি ধাপে ধাপে দেখাব কীভাবে একটি ডার্ক/লাইট মোড টগল বানাতে হয় – প্রতিটি লাইনের কাজ বাংলায় ব্যাখ্যা করে। আপনি যদি HTML/CSS/JS না জানেন, তাও চিন্তা নেই। এখানে সব কথা স্পষ্ট করে লেখা আছে।

⚡ এই বাটন ক্লিক করে পুরো পাতার রং বদলে দেখুন। (এটি ডেমো)

🎨 ১. CSS ভেরিয়েবল (Custom Properties) – রং সংরক্ষণ করা

নিচের কোডটি CSS অংশ। আমরা সব রংকে ভেরিয়েবলের ভিতরে রাখব, যাতে পরে এক জায়গায় বদলালেই সব জায়গায় রং বদলে যায়।

/* STEP 1: ডিফল্ট (লাইট) থিমের জন্য ভেরিয়েবল */
:root {
  --bg: #f8fafc;      /* পৃষ্ঠার পটভূমির রং (হালকা ধূসর) */
  --text: #0f172a;     /* সাধারণ লেখার রং (কালোর কাছাকাছি) */
  --accent: #2563eb;   /* বাটন, লিংকের রং (নীল) */
}

/* STEP 2: ডার্ক থিম – যখন body তে 'dark' ক্লাস থাকবে */
body.dark {
  --bg: #0f172a;       /* পটভূমি গাঢ় নীল */
  --text: #e2e8f0;     /* লেখা সাদার কাছাকাছি */
  --accent: #38bdf8;   /* আকাশী নীল */
}

/* STEP 3: ভেরিয়েবল ব্যবহার করা */
body {
  background: var(--bg);   /* পটভূমি ভেরিয়েবল অনুযায়ী */
  color: var(--text);      /* লেখার রং ভেরিয়েবল অনুযায়ী */
  transition: 0.3s;        /* রং বদলাতে ০.৩ সেকেন্ড সময় নেবে (মসৃণ) */
}
🔍 ব্যাখ্যা:
• :root – পুরো ডকুমেন্টের সবচেয়ে উপরের এলিমেন্ট। এখানে রাখা ভেরিয়েবল সব জায়গায় ব্যবহার করা যায়।
• --bg, --text – এগুলো কাস্টম ভেরিয়েবলের নাম। ড্যাশ (–) দিয়ে শুরু করতে হয়।
• body.dark – মানে যেকোনো body যার ক্লাসে 'dark' আছে। আমরা JavaScript দিয়ে এই ক্লাস যোগ/সরাব।
• var(--bg) – মানে '--bg' ভেরিয়েবলের ভ্যালু নাও।
• transition: 0.3s; – রং বদলাতে যখনই পরিবর্তন হবে, ০.৩ সেকেন্ড ধরে ধীরে হবে। চোখে আরামদায়ক।

🧩 ২. HTML বাটন – ব্যবহারকারী যেখানে ক্লিক করবে

শুধু একটি <button> এলিমেন্ট লাগবে।

<button id="themeToggle">🌙 ডার্ক মোড</button>
🔍 ব্যাখ্যা:
• id="themeToggle" – এই আইডি দিয়ে আমরা JavaScript এ বাটনটিকে চিনতে পারব।
• বাটনের ভেতরের টেক্সট – একটি ইমোজি (🌙) ও লেখা। পরে JavaScript দিয়ে টেক্সট বদলাব।

⚙️ ৩. জাভাস্ক্রিপ্ট – ক্লিক শোনা, ক্লাস টগল, পছন্দ মনে রাখা

এখানে প্রতিটি লাইনের কাজ স্পষ্ট করে বলা আছে।

// বাটন ধরা
const toggleBtn = document.getElementById('themeToggle');

// ক্লিক করলে
toggleBtn.addEventListener('click', () => {
  document.body.classList.toggle('dark');
  const isDark = document.body.classList.contains('dark');
  toggleBtn.textContent = isDark ? '☀️ লাইট মোড' : '🌙 ডার্ক মোড';
  localStorage.setItem('theme', isDark ? 'dark' : 'light');
});

// পূর্বের পছন্দ লোড
const savedTheme = localStorage.getItem('theme');
if (savedTheme === 'dark') {
  document.body.classList.add('dark');
  toggleBtn.textContent = '☀️ লাইট মোড';
}
🔍 লাইন বাই লাইন ব্যাখ্যা:
• const toggleBtn = document.getElementById('themeToggle'); – HTML-এর বাটনটিকে JavaScript-এ নিয়ে আসা।
• addEventListener('click', ...) – বাটনে ক্লিক করলে ফাংশন চালাবে।
• document.body.classList.toggle('dark'); – body তে 'dark' ক্লাস থাকলে সরাবে, না থাকলে যোগ করবে।
• const isDark = document.body.classList.contains('dark'); – 'dark' ক্লাস আছে কিনা true/false।
• toggleBtn.textContent = isDark ? '☀️ লাইট মোড' : '🌙 ডার্ক মোড'; – বাটনের লেখা বদলানো।
• localStorage.setItem('theme', isDark ? 'dark' : 'light'); – পছন্দ সংরক্ষণ।
• const savedTheme = localStorage.getItem('theme'); – পূর্বের পছন্দ পড়া।
• if (savedTheme === 'dark') { ... } – ডার্ক ছিল কিনা চেক করে সেট করা।

🎯 পুরো কোড একসাথে (কপি করে পেস্ট করুন)

আপনি চাইলে নিচের পুরো কোডটি আপনার HTML ফাইলে বসিয়ে দিন। তাহলেই ডার্ক মোড টগল কাজ করবে।

💡 প্র্যাকটিক্যাল টিপস

  • CSS ভেরিয়েবল আরও বাড়ান: আপনি চাইলে --border, --card-bg ইত্যাদি ভেরিয়েবল যোগ করে সব ডিজাইন পরিবর্তন করতে পারেন।
  • মসৃণ ট্রানজিশন: শুধু transition: 0.3s; দিলেই রং বদলাতে সময় লাগে, চোখে আরামদায়ক।
  • ব্রাউজার সাপোর্ট: CSS ভেরিয়েবল ও localStorage সব আধুনিক ব্রাউজারে কাজ করে (Chrome, Firefox, Edge, Safari)।
  • একাধিক পৃষ্ঠায় সংরক্ষণ: localStorage পুরো ওয়েবসাইটের জন্য একটি জায়গা, তাই এক পৃষ্ঠায় পছন্দ করলে অন্য পৃষ্ঠাতেও সেটি লোড হবে (একই ডোমেইনে)।
📢 শেষ কথা: এই টিউটোরিয়াল শেষ করে আপনি নিজেই বুঝতে পারবেন কীভাবে ডার্ক মোড টগল কাজ করে। যদি কোথাও আটকে যান, তাহলে কমেন্ট করে জানাতে পারেন। আমি সাহায্য করব।

🌙 Dark Mode Toggle – CSS Variables & JavaScript (Explained Line by Line)

📅 April 29, 2026 ⏱️ 10 min read ✍️ Milan Biswas

In this tutorial, I'll show you step by step how to build a dark/light mode toggle – explaining every single line of code. Even if you're a complete beginner, you'll be able to follow along.

⚡ Click this button to see the whole page change colors. (Demo)

🎨 1. CSS Variables (Custom Properties) – Storing Colors

:root {
  --bg: #f8fafc;      /* light background */
  --text: #0f172a;     /* dark text */
  --accent: #2563eb;   /* blue accent */
}
body.dark {
  --bg: #0f172a;       /* dark background */
  --text: #e2e8f0;     /* light text */
  --accent: #38bdf8;   /* light blue accent */
}
body {
  background: var(--bg);
  color: var(--text);
  transition: 0.3s;
}
Variables defined in :root, overridden in body.dark, then used with var().

🧩 2. HTML Button

<button id="themeToggle">🌙 Dark Mode</button>

⚙️ 3. JavaScript – Toggle & localStorage

const toggleBtn = document.getElementById('themeToggle');
toggleBtn.addEventListener('click', () => {
  document.body.classList.toggle('dark');
  const isDark = document.body.classList.contains('dark');
  toggleBtn.textContent = isDark ? '☀️ Light Mode' : '🌙 Dark Mode';
  localStorage.setItem('theme', isDark ? 'dark' : 'light');
});
const savedTheme = localStorage.getItem('theme');
if (savedTheme === 'dark') {
  document.body.classList.add('dark');
  toggleBtn.textContent = '☀️ Light Mode';
}
Click → toggle class → update button text → save to localStorage → load saved preference on page load.

🌙 डार्क मोड टॉगल – CSS वेरिएबल और JavaScript (हर लाइन की व्याख्या)

📅 29 अप्रैल, 2026 ⏱️ 10 मिनट पढ़ें ✍️ मिलन बिस्वास

इस ट्यूटोरियल में मैं चरण दर चरण बताऊंगा कि डार्क/लाइट मोड टॉगल कैसे बनाया जाता है – हर एक लाइन को हिंदी में समझाते हुए।

⚡ इस बटन पर क्लिक करके पूरे पेज के रंग बदलते देखें। (डेमो)

🎨 1. CSS वेरिएबल – रंग संग्रहित करना

:root {
  --bg: #f8fafc;      /* हल्की पृष्ठभूमि */
  --text: #0f172a;     /* गहरा टेक्स्ट */
  --accent: #2563eb;   /* नीला */
}
body.dark {
  --bg: #0f172a;       /* गहरी पृष्ठभूमि */
  --text: #e2e8f0;     /* हल्का टेक्स्ट */
  --accent: #38bdf8;   /* हल्का नीला */
}
body {
  background: var(--bg);
  color: var(--text);
  transition: 0.3s;
}
वेरिएबल :root में परिभाषित होते हैं, body.dark में ओवरराइड होते हैं, और var() से उपयोग किए जाते हैं।

<button id="themeToggle">🌙 डार्क मोड</button>
