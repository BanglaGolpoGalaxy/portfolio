📖 এই সিরিজ সম্পর্কে📖 About This Series

"মোবাইলেই ব্যাকএন্ড" একটি বাস্তবমুখী বাংলা টিউটোরিয়াল সিরিজ, যেখানে আমরা একটি বাস্তব দোকান ম্যানেজমেন্ট সিস্টেম তৈরি করতে করতে ফুল স্ট্যাক ডেভেলপমেন্ট শিখব।"Backend on Mobile" is a practical Bangla tutorial series where we learn full stack development by building a real shop management system.

✅ যা যা শিখবেন:✅ What You'll Learn:

  • Termux ইন্সটল ও কমান্ড লাইন মাস্টারিTermux installation & command line mastery
  • Node.js ও Express.js দিয়ে REST API তৈরিBuilding REST API with Node.js & Express.js
  • JSON ফাইল ডেটাবেস হিসেবে ব্যবহারUsing JSON files as database
  • CRUD অপারেশন (GET, POST, PUT, DELETE)CRUD operations (GET, POST, PUT, DELETE)
  • ফ্রন্টএন্ড HTML/CSS/JS দিয়ে API কল করাFrontend HTML/CSS/JS API calls
  • বিলিং ও স্টক ম্যানেজমেন্ট লজিকBilling & stock management logic
  • JWT লগইন ও সিকিউরিটিJWT login & security
  • লাভ-ক্ষতি রিপোর্ট ও ড্যাশবোর্ডProfit-loss report & dashboard
  • SQLite ডেটাবেস ব্যবহারUsing SQLite database
  • প্রজেক্ট GitHub ও অনলাইনে লাইভ করাDeploying project to GitHub & online
