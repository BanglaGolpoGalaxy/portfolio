👨‍💻 আমার সম্পর্কে

নমস্কার! আমি Milan Biswas, একজন ওয়েব ডেভেলপার, টিউটোরিয়াল ক্রিয়েটর ও প্রযুক্তি উৎসাহী।

📌 আমি কে?

আমি পশ্চিমবঙ্গ, ভারতের বাসিন্দা। ২০২১ সালে বি.এসসি ডিগ্রি সম্পন্ন করেছি এবং বর্তমানে ITI COPA (Computer Operator and Programming Assistant) কোর্স করছি। পেশাগত জীবনে শিক্ষকতা, ম্যানেজমেন্ট, ডেটা এন্ট্রি ও কাস্টমার রিলেশন-এ কাজ করার অভিজ্ঞতা আছে।

🛠️ আমি কী করি?

আমি মোবাইল ফোন থেকেই ফুল-স্ট্যাক ওয়েব অ্যাপ্লিকেশন তৈরি করি। Termux, Node.js, Express, SQLite, JWT ব্যবহার করে প্রোজেক্ট বানাই এবং Render বা GitHub Pages-এ ডেপ্লয় করি।

  • HTML, CSS, JavaScript (ES6)
  • Node.js, Express.js, REST API
  • SQLite, MongoDB
  • Git, GitHub, Termux
  • JWT Authentication, QR Code

📚 কেন লিখি?

আমি বাংলায় ফ্রি টিউটোরিয়াল লিখি, যাতে বাংলাভাষীরা সহজেই ওয়েব ডেভেলপমেন্ট শিখতে পারে। আমার লক্ষ্য হলো শিক্ষাকে সহজলভ্য ও মজাদার করে তোলা – এমনকি যাদের ল্যাপটপ বা ব্যয়বহুল কোর্সের সুযোগ নেই, তারাও যেন শিখতে পারে।

👨‍💻 About Me

Hello! I'm Milan Biswas, a web developer, tutorial creator, and tech enthusiast.

📌 Who I Am

I'm from West Bengal, India. I completed my B.Sc in 2021 and am currently enrolled in the ITI COPA (Computer Operator and Programming Assistant) course. I have professional experience in teaching, management, data entry, and customer relations.

🛠️ What I Do

I build full-stack web applications entirely from my mobile phone. I use Termux, Node.js, Express, SQLite, and JWT to create projects and deploy them on Render or GitHub Pages.

  • HTML, CSS, JavaScript (ES6)
  • Node.js, Express.js, REST API
  • SQLite, MongoDB
  • Git, GitHub, Termux
  • JWT Authentication, QR Code

📚 Why I Write

I write free tutorials in Bengali so that Bengali speakers can easily learn web development. My goal is to make education accessible and fun – even for those who don't have a laptop or expensive courses.

🚀 My Goals

  • Projects: AadimVault, Shop Manager, Super Calculator, Exam Guide India
  • Community: Contribute to open-source projects and create Bengali tutorials
  • Freelancing: Build high-quality web solutions for clients
