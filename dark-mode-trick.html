🌙 ডার্ক মোড টগল – CSS ভেরিয়েবল ও JavaScript (সবকিছু লাইন ধরে বুঝুন)

📅 ২৯ এপ্রিল, ২০২৬ ⏱️ ১০ মিনিট পড়া ✍️ মিলন বিশ্বাস

এই টিউটোরিয়ালে আমি ধাপে ধাপে দেখাব কীভাবে একটি ডার্ক/লাইট মোড টগল বানাতে হয় – প্রতিটি লাইনের কাজ বাংলায় ব্যাখ্যা করে। আপনি যদি HTML/CSS/JS না জানেন, তাও চিন্তা নেই। এখানে সব কথা স্পষ্ট করে লেখা আছে।

⚡ এই বাটন ক্লিক করে পুরো পাতার রং বদলে দেখুন। (এটি ডেমো)

🎨 ১. CSS ভেরিয়েবল (Custom Properties) – রং সংরক্ষণ করা

নিচের কোডটি CSS অংশ। আমরা সব রংকে ভেরিয়েবলের ভিতরে রাখব, যাতে পরে এক জায়গায় বদলালেই সব জায়গায় রং বদলে যায়।

/* STEP 1: ডিফল্ট (লাইট) থিমের জন্য ভেরিয়েবল */
:root {
  --bg: #f8fafc;      /* পৃষ্ঠার পটভূমির রং (হালকা ধূসর) */
  --text: #0f172a;     /* সাধারণ লেখার রং (কালোর কাছাকাছি) */
  --accent: #2563eb;   /* বাটন, লিংকের রং (নীল) */
}

/* STEP 2: ডার্ক থিম – যখন body তে 'dark' ক্লাস থাকবে */
body.dark {
  --bg: #0f172a;       /* পটভূমি গাঢ় নীল */
  --text: #e2e8f0;     /* লেখা সাদার কাছাকাছি */
  --accent: #38bdf8;   /* আকাশী নীল */
}

/* STEP 3: ভেরিয়েবল ব্যবহার করা */
body {
  background: var(--bg);   /* পটভূমি ভেরিয়েবল অনুযায়ী */
  color: var(--text);      /* লেখার রং ভেরিয়েবল অনুযায়ী */
  transition: 0.3s;        /* রং বদলাতে ০.৩ সেকেন্ড সময় নেবে (মসৃণ) */
}
🔍 ব্যাখ্যা:
• :root – পুরো ডকুমেন্টের সবচেয়ে উপরের এলিমেন্ট। এখানে রাখা ভেরিয়েবল সব জায়গায় ব্যবহার করা যায়।
• --bg, --text – এগুলো কাস্টম ভেরিয়েবলের নাম। ড্যাশ (–) দিয়ে শুরু করতে হয়।
• body.dark – মানে যেকোনো body যার ক্লাসে 'dark' আছে। আমরা JavaScript দিয়ে এই ক্লাস যোগ/সরাব।
• var(--bg) – মানে '--bg' ভেরিয়েবলের ভ্যালু নাও।
• transition: 0.3s; – রং বদলাতে যখনই পরিবর্তন হবে, ০.৩ সেকেন্ড ধরে ধীরে হবে। চোখে আরামদায়ক।

🧩 ২. HTML বাটন – ব্যবহারকারী যেখানে ক্লিক করবে

শুধু একটি <button> এলিমেন্ট লাগবে।

<button id="themeToggle">🌙 ডার্ক মোড</button>
🔍 ব্যাখ্যা:
• id="themeToggle" – এই আইডি দিয়ে আমরা JavaScript এ বাটনটিকে চিনতে পারব।
• বাটনের ভেতরের টেক্সট – একটি ইমোজি (🌙) ও লেখা। পরে JavaScript দিয়ে টেক্সট বদলাব।

⚙️ ৩. জাভাস্ক্রিপ্ট – ক্লিক শোনা, ক্লাস টগল, পছন্দ মনে রাখা

এখানে প্রতিটি লাইনের কাজ স্পষ্ট করে বলা আছে।

<script>
  // ধাপ ১: বাটন এলিমেন্টটি ধরে আনা
  const toggleBtn = document.getElementById('themeToggle');

  // ধাপ ২: বাটনে ক্লিক করলে কী হবে?
  toggleBtn.addEventListener('click', () => {
    // body এলিমেন্টে 'dark' ক্লাস থাকলে সরাও, না থাকলে যোগ করো
    document.body.classList.toggle('dark');

    // চেক করো এখন 'dark' ক্লাস আছে কিনা
    const isDark = document.body.classList.contains('dark');

    // বাটনের লেখা বদলাও: ডার্ক মোড মানে 'লাইট মোড' লেখা দেখাবে
    toggleBtn.textContent = isDark ? '☀️ লাইট মোড' : '🌙 ডার্ক মোড';

    // ব্যবহারকারীর পছন্দ localStorage-এ সংরক্ষণ করো
    localStorage.setItem('theme', isDark ? 'dark' : 'light');
  });

  // ধাপ ৩: পেজ লোড হওয়ার সময় পূর্বের পছন্দ লোড করো
  const savedTheme = localStorage.getItem('theme');
  if (savedTheme === 'dark') {
    document.body.classList.add('dark');
    toggleBtn.textContent = '☀️ লাইট মোড';
  }
</script>
🔍 লাইন বাই লাইন ব্যাখ্যা:
• const toggleBtn = document.getElementById('themeToggle'); – HTML-এর বাটনটিকে JavaScript-এ নিয়ে আসা।
• addEventListener('click', ...) – বাটনে ক্লিক করলে দ্বিতীয় আর্গুমেন্টের ফাংশনটি চালাবে।
• document.body.classList.toggle('dark'); – <body> ট্যাগের ক্লাস লিস্টে 'dark' থাকলে সরাবে, না থাকলে যোগ করবে।
• const isDark = document.body.classList.contains('dark'); – বর্তমানে 'dark' ক্লাস আছে কিনা true/false রিটার্ন করে।
• toggleBtn.textContent = isDark ? '☀️ লাইট মোড' : '🌙 ডার্ক মোড'; – টার্নারি অপারেটর: if isDark true হলে 'লাইট মোড' লেখা, নইলে 'ডার্ক মোড'।
• localStorage.setItem('theme', value); – ব্রাউজারের অভ্যন্তরীণ স্টোরেজে 'theme' নামে ভ্যালু সেভ করে।
• const savedTheme = localStorage.getItem('theme'); – স্টোরেজ থেকে 'theme' পড়ে আনা।
• if (savedTheme === 'dark') { ... } – যদি পূর্বের পছন্দ ডার্ক ছিল, তাহলে সেই অনুযায়ী ক্লাস ও বাটনের লেখা সেট করা।

🌙 Dark Mode Toggle – CSS Variables & JavaScript (Explained Line by Line)

📅 April 29, 2026 ⏱️ 10 min read ✍️ Milan Biswas

In this tutorial, I'll show you step by step how to build a dark/light mode toggle – explaining every single line of code. Even if you're a complete beginner, you'll be able to follow along.

⚡ Click this button to see the whole page change colors. (Demo)

🎨 1. CSS Variables (Custom Properties) – Storing Colors

The CSS part stores all colors in variables so that we only have to change them in one place.

/* STEP 1: Default (light) theme variables */
:root {
  --bg: #f8fafc;      /* page background (light grey) */
  --text: #0f172a;     /* main text color (near black) */
  --accent: #2563eb;   /* accent color for buttons/links (blue) */
}

/* STEP 2: Dark theme – when the body has the 'dark' class */
body.dark {
  --bg: #0f172a;       /* background becomes dark blue */
  --text: #e2e8f0;     /* text becomes near white */
  --accent: #38bdf8;   /* accent becomes light blue */
}

/* STEP 3: Using the variables */
body {
  background: var(--bg);   /* background follows the variable */
  color: var(--text);      /* text follows the variable */
  transition: 0.3s;        /* smooth 0.3 second color change */
}
🔍 Explanation:
• :root – the highest element of the document; variables defined here are available everywhere.
• --bg, --text – custom property names, always start with two dashes.
• body.dark – targets the <body> only when it has the class "dark". We'll toggle this class with JavaScript.
• var(--bg) – reads the value of the --bg variable.
• transition: 0.3s; – makes color changes smooth over 0.3 seconds.

🧩 2. HTML Button – The Element Users Click

All we need is a single <button>.

<button id="themeToggle">🌙 Dark Mode</button>
🔍 Explanation:
• id="themeToggle" – this id lets JavaScript find the button easily.
• The button text has an emoji (🌙) and some words. We’ll change it dynamically with JavaScript.

⚙️ 3. JavaScript – Listening to Clicks, Toggling Classes, Remembering Preferences

Each line is explained below.

<script>
  // Step 1: grab the button element
  const toggleBtn = document.getElementById('themeToggle');

  // Step 2: what happens when the button is clicked?
  toggleBtn.addEventListener('click', () => {
    // Add/remove the 'dark' class on the body
    document.body.classList.toggle('dark');

    // Check whether the 'dark' class is now present
    const isDark = document.body.classList.contains('dark');

    // Update the button text accordingly
    toggleBtn.textContent = isDark ? '☀️ Light Mode' : '🌙 Dark Mode';

    // Save the user's preference in localStorage
    localStorage.setItem('theme', isDark ? 'dark' : 'light');
  });

  // Step 3: when the page loads, restore the saved preference
  const savedTheme = localStorage.getItem('theme');
  if (savedTheme === 'dark') {
    document.body.classList.add('dark');
    toggleBtn.textContent = '☀️ Light Mode';
  }
</script>
🔍 Line-by-line explanation:
• const toggleBtn = document.getElementById('themeToggle'); – selects the button from the HTML.
• addEventListener('click', ...) – runs the provided function whenever the button is clicked.
• document.body.classList.toggle('dark'); – if the 'dark' class is present it removes it; if not, it adds it.
• const isDark = document.body.classList.contains('dark'); – returns true if the class is currently there.
• toggleBtn.textContent = isDark ? '☀️ Light Mode' : '🌙 Dark Mode'; – ternary operator: if isDark is true show 'Light Mode', otherwise 'Dark Mode'.
• localStorage.setItem('theme', value); – stores a value named 'theme' in the browser's internal storage.
• const savedTheme = localStorage.getItem('theme'); – reads the stored theme.
• if (savedTheme === 'dark') { ... } – applies the dark theme if it was previously saved.

🌙 डार्क मोड टॉगल – CSS वेरिएबल और JavaScript (हर लाइन की व्याख्या)

📅 29 अप्रैल, 2026 ⏱️ 10 मिनट में पढ़ें ✍️ मिलन बिस्वास

इस ट्यूटोरियल में मैं कदम दर कदम बताऊंगा कि डार्क/लाइट मोड टॉगल कैसे बनाया जाता है – हर एक लाइन की व्याख्या हिंदी में। यदि आपको HTML/CSS/JS नहीं आता, तो भी चिंता की बात नहीं। सब कुछ सरल शब्दों में समझाया गया है।

⚡ इस बटन पर क्लिक करके पूरे पेज का रंग बदलते हुए देखें। (डेमो)

🎨 1. CSS वेरिएबल (Custom Properties) – रंग सहेजना

नीचे दिया गया कोड CSS का भाग है। हम सभी रंगों को वेरिएबलों में रखेंगे ताकि बाद में एक जगह बदलने पर सभी जगह रंग बदल जाए।

/* STEP 1: डिफ़ॉल्ट (लाइट) थीम के लिए वेरिएबल */
:root {
  --bg: #f8fafc;      /* पृष्ठभूमि का रंग (हल्का स्लेटी) */
  --text: #0f172a;     /* टेक्स्ट का रंग (गहरा) */
  --accent: #2563eb;   /* बटन, लिंक का रंग (नीला) */
}

/* STEP 2: डार्क थीम – जब body में 'dark' क्लास हो */
body.dark {
  --bg: #0f172a;       /* पृष्ठभूमि गहरा नीला */
  --text: #e2e8f0;     /* टेक्स्ट सफ़ेद के करीब */
  --accent: #38bdf8;   /* हल्का नीला */
}

/* STEP 3: वेरिएबलों का उपयोग */
body {
  background: var(--bg);   /* पृष्ठभूमि वेरिएबल के अनुसार */
  color: var(--text);      /* टेक्स्ट वेरिएबल के अनुसार */
  transition: 0.3s;        /* रंग बदलने में 0.3 सेकंड लगेंगे (धीरे-धीरे) */
}
🔍 व्याख्या:
• :root – पूरे दस्तावेज़ का सबसे ऊपरी एलिमेंट। यहां दिए वेरिएबल हर जगह उपलब्ध होते हैं।
• --bg, --text – ये कस्टम वेरिएबल नाम हैं। दो डैश (–) से शुरू करना ज़रूरी है।
• body.dark – किसी भी body को चुनता है जिसमें 'dark' क्लास हो। हम JavaScript से इस क्लास को जोड़ेंगे/हटाएंगे।
• var(--bg) – '--bg' वेरिएबल का मान लेता है।
• transition: 0.3s; – जब भी रंग बदलेगा, 0.3 सेकंड में धीरे-धीरे होगा। आँखों को आराम।

🧩 2. HTML बटन – जिस पर उपयोगकर्ता क्लिक करेंगे

सिर्फ एक <button> एलिमेंट चाहिए।

<button id="themeToggle">🌙 डार्क मोड</button>
🔍 व्याख्या:
• id="themeToggle" – इस आईडी से हम JavaScript में बटन को पहचानेंगे।
• बटन के अंदर का टेक्स्ट – एक इमोजी (🌙) और लेख। बाद में JavaScript से टेक्स्ट बदलेंगे।

⚙️ 3. जावास्क्रिप्ट – क्लिक सुनना, क्लास टॉगल करना, पसंद याद रखना

यहाँ हर पंक्ति का काम साफ़-साफ़ बताया गया है।

<script>
  // चरण 1: बटन एलिमेंट को पकड़ें
  const toggleBtn = document.getElementById('themeToggle');

  // चरण 2: बटन पर क्लिक करने पर क्या होगा?
  toggleBtn.addEventListener('click', () => {
    // body पर 'dark' क्लास को टॉगल करें (है तो हटाएं, नहीं तो जोड़ें)
    document.body.classList.toggle('dark');

    // जाँचें कि अब 'dark' क्लास मौजूद है या नहीं
    const isDark = document.body.classList.contains('dark');

    // बटन का टेक्स्ट बदलें: डार्क मोड होने पर 'लाइट मोड' दिखाएं
    toggleBtn.textContent = isDark ? '☀️ लाइट मोड' : '🌙 डार्क मोड';

    // उपयोगकर्ता की पसंद को localStorage में सहेजें
    localStorage.setItem('theme', isDark ? 'dark' : 'light');
  });

  // चरण 3: पेज लोड होने पर पिछली पसंद को बहाल करें
  const savedTheme = localStorage.getItem('theme');
  if (savedTheme === 'dark') {
    document.body.classList.add('dark');
    toggleBtn.textContent = '☀️ लाइट मोड';
  }
</script>
🔍 पंक्ति-दर-पंक्ति व्याख्या:
• const toggleBtn = document.getElementById('themeToggle'); – HTML से बटन को लाना।
• addEventListener('click', ...) – क्लिक पर दिए गए फंक्शन को चलाना।
• document.body.classList.toggle('dark'); – अगर 'dark' क्लास है तो हटाएगा, नहीं तो जोड़ेगा।
• const isDark = document.body.classList.contains('dark'); – true देता है यदि क्लास उपस्थित है।
• toggleBtn.textContent = isDark ? '☀️ लाइट मोड' : '🌙 डार्क मोड'; – यदि isDark सही है तो 'लाइट मोड' दिखाएं, अन्यथा 'डार्क मोड'।
• localStorage.setItem('theme', value); – ब्राउज़र के स्टोरेज में 'theme' नाम से मान सहेजना।
• const savedTheme = localStorage.getItem('theme'); – स्टोरेज से 'theme' पढ़ना।
• if (savedTheme === 'dark') { ... } – यदि पहले से डार्क थीम चुनी थी तो उसे लागू करना।

🎯 संपूर्ण कोड (कॉपी करके पेस्ट करें)

नीचे दिया गया पूरा कोड अपनी HTML फ़ाइल में डालें और डार्क मोड टॉगल काम करने लगेगा।

<!DOCTYPE html>
<html>
<head>
  <style>
    :root {
      --bg: #f8fafc;
      --text: #0f172a;
      --accent: #2563eb;
    }
    body.dark {
      --bg: #0f172a;
      --text: #e2e8f0;
      --accent: #38bdf8;
    }
    body {
      background: var(--bg);
      color: var(--text);
      transition: 0.3s;
      font-family: sans-serif;
      padding: 2rem;
    }
    button {
      background: var(--accent);
      color: white;
      border: none;
      padding: 10px 20px;
      border-radius: 40px;
      cursor: pointer;
    }
  </style>
</head>
<body>
  <button id="themeToggle">🌙 डार्क मोड</button>
  <h1>मेरी वेबसाइट</h1>
  <p>इस पेज पर डार्क/लाइट मोड टॉगल है।</p>
  <script>
    const btn = document.getElementById('themeToggle');
    btn.addEventListener('click', () => {
      document.body.classList.toggle('dark');
      const isDark = document.body.classList.contains('dark');
      btn.textContent = isDark ? '☀️ लाइट मोड' : '🌙 डार्क मोड';
      localStorage.setItem('theme', isDark ? 'dark' : 'light');
    });
    if (localStorage.getItem('theme') === 'dark') {
      document.body.classList.add('dark');
      btn.textContent = '☀️ लाइट मोड';
    }
  </script>
</body>
</html>

💡 व्यावहारिक सुझाव

  • CSS वेरिएबल बढ़ाएँ: --border, --card-bg जैसे और वेरिएबल बनाकर पूरा डिज़ाइन नियंत्रित कर सकते हैं।
  • स्मूथ ट्रांज़िशन: transition: 0.3s; देने मात्र से रंग बदलने में समय लगता है, आँखों को सुकून मिलता है।
  • ब्राउज़र सपोर्ट: CSS वेरिएबल और localStorage सभी आधुनिक ब्राउज़रों (Chrome, Firefox, Edge, Safari) में काम करते हैं।
  • कई पृष्ठों पर याद रखना: localStorage पूरी वेबसाइट के लिए साझा होता है, इसलिए एक पृष्ठ पर चुनी गई थीम दूसरे पृष्ठ पर भी लागू रहेगी।
